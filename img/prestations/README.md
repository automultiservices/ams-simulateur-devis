# Photos des prestations

Déposer ici, pour chaque prestation, 2 fichiers WebP générés par l’onglet **Photos** de l’espace admin :

- `<nom>.webp` : grande photo (1200 px)
- `<nom>-mini.webp` : miniature (160 px)

Le `<nom>` doit correspondre au champ « Photo » de la prestation (onglet Prestations & prix).
